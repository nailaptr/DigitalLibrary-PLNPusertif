# Antigravity Setup — Monitoring Temuan

1. Copy the contents of this pack into the repository root, merging with existing files.
2. Keep the original source files under `docs/monitoring-temuan/source/`.
3. Keep the PRD PDF at `docs/monitoring-temuan/PRD-Monitoring-Temuan.pdf`.
4. Start with Phase 0, then run one phase per fresh Antigravity conversation.
5. After every phase, check `IMPLEMENTATION-STATE.md` before starting the next one.
6. If a phase needs detailed rules, Antigravity can use `.agents/rules/monitoring-temuan.md` via model decision instead of injecting the whole rule file on every turn.
